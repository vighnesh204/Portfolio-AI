# Vighnesh — Developer Portfolio

A premium, handcrafted developer portfolio built with React, Vite, Tailwind CSS, GSAP, and React Router.

---

## Tech Stack

- **React 19** + **Vite 8**
- **Tailwind CSS v4**
- **React Router v7**
- **GSAP 3** + ScrollTrigger

---

## Setup

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Production build
npm run build

# Preview production build
npm run preview
```
